正弦定理の証明

三角形の辺とその対角の正弦（sin）の比は、外接円の直径に等しい。

a / sin A = b / sin B = c / sin C = 2R

点 A をドラッグ（またはスライダーで操作）すると、鋭角三角形・鈍角三角形のどちらでも a/sinA が外接円の直径 2R と常に一致することを確認できます。点B・Cは固定です。

証明（外接円を用いる方法）

  1. 三角形ABCの外接円の中心をO、半径をRとする。
  2. 頂点Bを通る直径を引き、円周上の反対側の端点をB'とする（BB' = 2R）。
  3. B'Cは直径BB'を見込む円周角なので、∠BCB' = 90°（直径に対する円周角は常に直角）。図で確認すると現在 -° になっている。
  4. 弧BCに対する円周角の定理より、点Aが点B'と弧BCの同じ側にあるとき ∠BB'C = ∠A。反対側にあるとき（四角形ABCB'が円に内接するため）∠BB'C = 180° − ∠A。どちらの場合も sin(∠BB'C) = sin A（点Aをドラッグして両方のケースを試せます）。
  5. 直角三角形BCB'において、sin(∠BB'C) = BC / BB' = a / 2R。
  6. 4と5より sin A = a / 2R、すなわち a / sin A = 2R。
  7. 同様に頂点A、頂点Cを通る直径を考えれば b/sinB = 2R、c/sinC = 2R も示せる（対称性より）。
  8. 以上より a/sinA = b/sinB = c/sinC = 2R（正弦定理）。∠A = 90°の場合は a がそのまま直径2Rとなり自明に成立する。
