余弦定理の証明

三角形の1辺の長さの2乗は、残り2辺の2乗の和から、その2辺とその間の角のコサインを使った項を引いたものに等しい。

c² = a² + b² − 2ab・cos C

点 A をドラッグすると、∠C が鋭角・鈍角のどちらでも上の式が成り立つことを確認できます。頂点C・Bはx軸上に固定、辺c（AB）の長さも固定されているため、Aは点Bを中心とする円周（点線）上だけを動きます。

証明（座標とピタゴラスの定理を用いる）

  1. 頂点Cを原点、頂点Bをx軸上の点 (a, 0) に置く座標平面を考える。
  2. 頂点Aから辺CB（x軸）に下ろした垂線の足をHとすると、CH = b・cos C、AH = b・sin C と表せる（∠Cが鈍角のときCHは負の値になり、Hは線分CBの外側に出る）。
  3. 直角三角形AHCにピタゴラスの定理を使うと、AH² + CH² = b²（これは cos²C + sin²C = 1 そのもの）。
  4. 直角三角形AHBにピタゴラスの定理を使うと、AH² + BH² = c²。ここで BH = a − CH（Hがどちらの位置にあっても、符号付きの座標差としてこの式は常に成り立つ）。
  5. c² = AH² + (a − CH)² = AH² + CH² − 2a・CH + a² = b² − 2a(b・cos C) + a²（3の結果を代入）。
  6. 整理すると c² = a² + b² − 2ab・cos C。∠Cが鈍角でcos Cが負になっても、符号がそのまま計算に反映されるので式はそのまま成り立つ。
